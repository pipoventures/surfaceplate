## Decision

1. `surfaceplate check` gains `--format text|json|sarif`. JSON first; SARIF 2.1.0 with
   `partialFingerprints` and a rules list, which is what GitHub code scanning ingests.
2. Exit codes become: `0` pass, or graced findings (`WARN`) with a printed summary; `1` findings
   that fail; `2` not installed; `3` usage error or no terminal; `4` internal error. `adopt`
   returns the checker's code after a successful write, so a first adoption of an existing
   repository, which produces graced findings by design, does not fail.
3. `surfaceplate adopt --propose` runs discovery and writes
   `governance/application-profile.proposed.yaml` and the answers record with every undecided
   decision marked `needs-human`. It never writes the profile. `surfaceplate adopt --answers
   <file>` replays a human-completed answers record through the same `plan`, `sections` and
   `_verify` code as the interface and writes the profile. There is no `--yes`: a run with no
   human answering may not write a level, a rationale or a scope decision.
4. `surfaceplate doctor`, offline by default: Python and pip, `core.hooksPath` at every scope,
   whether a terminal is attached, whether the virtualenv is on `PATH`, the vendored copy's
   digest against the install record. Anything needing a token is behind `--online`.
5. A real argument parser, with `--version` and `--help` at the top level.
6. The README pass permitted now by `org/RELEASE_PLAN.md` is bounded to: the three commands;
   the version line; the two links to a `core/` that does not exist; the extras form
   `surfaceplate[adopt] @ git+…`; one sentence on a global `core.hooksPath`. `INSTALL.md` gains
   `surfaceplate install` and `check`, and loses the pointer to
   `prompts/copilot-implementation-assistant.prompt.md`, which the payload does not carry. The
   documentation restructure and any retirement of `SETUP_GUIDE.md` wait for the release plan's
   item 8 and a separate decision.

## Context and alternatives

The review's stranger install failed at its first command on a machine with a global hooks path
that the README does not mention; `surfaceplate --help` printed a usage line and exited 2; exit
2 covered four unrelated conditions; and `adopt` had no path that did not need a terminal
(`F70`). Alternative considered: add formats without changing codes (rejected: the overloaded
exit 2 is what prevents any wrapper from distinguishing "not installed" from "no terminal").

## Impact

- Numerical/model output: none.
- Contracts/schemas: exit codes and output formats are public contracts; the installed hook and
  workflow that read them are updated in the same change and reinstalled.
- Security/data: `doctor --online` constructs a request to GitHub with a token; it is a trust
  boundary and gets explicit review in `ACT-045`. The answers record must never carry secrets;
  `--propose` output is reviewed before commit like any file.
- Reproducibility/lineage: `--answers` makes an adoption replayable for the first time.
- Operations/release: none beyond the reinstall the change needs.
