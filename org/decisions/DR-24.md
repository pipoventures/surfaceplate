# Decision Record

- Decision ID: DR-24
- Date: 2026-08-31
- Application: Surfaceplate (the framework itself).
- Decision owner: Mario Pipo (maintainer).
- Status: accepted — implemented in the same change.
- Risk level: 2 — it sets the terms under which every copied file is licensed, on an artefact that
  is already public.
- Related work item: `ACT-009`. Closes `F19`.

## Decision

**Surfaceplate is licensed by artefact type: software under Apache-2.0, documents under CC0-1.0.**

| Licence | Paths |
|---|---|
| **Apache-2.0** (`LICENSE`) | `scripts/`, `tests/`, `schemas/`, `adapters/`, `standard/.githooks/`, `standard/.github/workflows/`, and everything not listed below |
| **CC0-1.0** (`LICENSE-DOCS`) | `core/`, `templates/`, `standard/.github/instructions/`, `standard/.github/skills/`, `standard/conformance-block.md` |

`NOTICE` is present as Apache-2.0 requires. `README.md` carries a Licensing section stating the
split.

**This record implements a decision taken elsewhere; it does not take one.** The choice and its
reasoning are recorded in `hermes` (2026-08-30, "Surfaceplate licensing and publication timing",
amended the same day by the cross-provider review that replaced CC BY 4.0 with CC0-1.0). Per the
standing constraint that commercial reasoning does not live in this repository, that rationale is
**cited and not restated**. What belongs here, and is recorded here, is the architectural
consequence: which licence covers which paths, and why the boundary falls where it does.

## Context and alternatives

### Why this record exists at all

`F19`: the decision was recorded in `hermes` on 2026-08-30 and **never implemented here**.
`LICENSE-DOCS` and `NOTICE` did not exist, and `README.md` contained no occurrence of the word
"licence". The repository was published in that state, so every template and agent skill shipped
under a licence the decision says should not govern prose.

### The boundary, and a correction made while drawing it

The boundary was first drawn as *"`standard/` + `templates/` + skills"* — a path rule, simple to
state, and **wrong in both directions**. Mapping it onto the actual payload showed it would have
placed:

- `core/` — the standard's own normative text, which the source decision names explicitly as a
  document — under the **software** licence;
- `standard/.githooks/pre-commit`, a shell script, and `standard/.github/workflows/`, CI
  configuration — under a **public-domain dedication**.

The source decision splits by *artefact type*, not by directory: *"all code: conformance checker,
installer, release builder, test suite, schemas, stack adapters"* against *"the standard text,
governance file templates and agent task skills, which are documents rather than software"*. The
corrected boundary follows that wording. A directory listing is not an artefact classification, and
the two disagree here.

### Why schemas and adapters are software

Both install into an adopting repository alongside the documents, and both are written in YAML or
Markdown, so the intuitive grouping puts them with the documents. The source decision names both as
code, and the reasoning holds independently: a schema is a **contract a program parses**, not prose
a human reads, and an adapter is stack-specific technical guidance rather than part of the standard.
Keeping them under Apache-2.0 keeps the patent grant attached to them.

This is the one place where the split will surprise a reader, so `README.md` says it explicitly
rather than leaving it to be inferred from a table.

### Alternatives rejected

- **Single licence, Apache-2.0 throughout.** The status quo, and the state the repository was
  published in. It puts an attribution and notice obligation on every governance file an adopter
  copies, which is friction working directly against adoption of a standard.
- **Everything copied into an adopter becomes CC0.** Simplest rule for an adopter to reason about,
  and rejected on two grounds: it contradicts the source decision on two named items, and it would
  place the conformance checker in the public domain — forfeiting the patent grant that is the
  stated reason for preferring Apache-2.0 over MIT in the first place.
- **Keeping the path-based boundary that was locked before the mapping was done.** Rejected once it
  was shown to contradict the decision it implements. Applying it would have been the same failure
  as `F19` at smaller scale: a decision recorded in one place, and something else done in practice.

## Impact

- **Numerical/model output:** none.
- **Contracts/schemas:** none — `schemas/` are unchanged and remain Apache-2.0.
- **Security/data:** none.
- **Operations/release:** `LICENSE-DOCS` and `NOTICE` enter the release payload, so the manifest and
  the distribution-identity anchor both change. An adopter copying a governance template now incurs
  no attribution obligation; one copying the checker still receives the patent grant.
- **Already-published state.** The repository was public under Apache-2.0 alone for part of
  2026-08-31. CC0 is a broadening rather than a restriction, so nobody's position is worsened by the
  correction, and no copy taken in the interim is invalidated.

## Evidence

- **The CC0-1.0 text was fetched, not written from memory.** Retrieved from
  `creativecommons.org/publicdomain/zero/1.0/legalcode.txt` and diffed **byte-for-byte** against the
  SPDX licence-list copy: identical, 7048 bytes, 121 lines. Legal text is exactly where reproducing
  from recall fails silently.
- Every path named in `README.md` and in the table above was checked to exist before being written.
- The boundary was verified against the real payload — 22 of 43 installed files fall on the document
  side under the corrected rule — rather than assumed from directory names.

## Limitations and follow-up

- **A licence boundary is a human judgement and nothing checks it.** No test asserts that a new file
  lands under the intended licence. A file added to `core/` is CC0 by this record and by nothing
  else; if the boundary matters enough to enforce, that is unbuilt work.
- **This record is downstream of another repository.** If the `hermes` decision changes again, this
  record does not learn of it — which is `F19`'s open half, recorded there rather than solved here.
- **No legal advice was taken**, here or in the source decision. This states a choice and its
  mechanics; it is not a legal opinion.
