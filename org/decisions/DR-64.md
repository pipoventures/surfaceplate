## Decision

1. **What closes `F6`.** Three values agree, computed by a **named non-maintainer** on their own
   machine from public artefacts, and attested in a schema-valid assurance-evidence record of type
   `independent_validation` with a stated `independence_basis`: **A**, the reviewer's own SHA-256 of
   `surfaceplate/MANIFEST.sha256` inside the source distribution fetched from PyPI, computed with
   `sha256sum` or the standard-library one-liner and never with a script from the package; **B**,
   the anchor the released tool declares about itself, skippable and then a stated limitation;
   **C**, the anchor the packet states, computed from the **published commit's** manifest. The
   maintainer's act on receipt is acceptance and filing, not attestation.
2. **The packet's form.** A tracked Markdown source (`audit/INDEPENDENT_REVIEW_PACKET.md`) with
   placeholders, rendered by `scripts/build_review_packet.py` into one self-contained HTML page
   (inline style, one inline script, no network) that carries the commands, the three values, the
   full-archive audit prompt verbatim from its evidence-handling section with one stated
   substitution, one row per `AUDIT_SCOPE.md` criterion, and a form that composes the record. The
   page is a build output, never committed; its digest is quoted in the message that carries it.
3. **Two records, not one.** `AE-0002-framework-anchor.yaml` for `H4` and, only when the audit was
   done, `AE-0003-independent-audit.yaml` for `H6`, so an outcome is never ambiguous; an anchor-only
   record says in its limitations that it does not bear on `H6`.
4. **The expected anchor comes from the published commit**, read with `git show`, never from the
   working tree at generation time and never from this repository's own profile, whose pin lags by
   construction (the self-install lag the profile's comment states). The generator refuses an
   archive whose inner manifest does not hash to that anchor.
5. **The published release is named by commit, not by tag** (`F115`): the `v0.16.0` tag points at a
   tree 235 commits older than the one published.

## Context and alternatives

Two cross-provider reviews could not compute the anchor and said so; `F6` has been open since the
first audit because every value of the anchor was computed and compared by one party. Not chosen:
a committed HTML page (a generated file that drifts from its source; the source is committed and
checked instead); one record for both actions (an audit `FAIL` and an anchor match would share one
`outcome`); comparing against this repository's profile (wrong by construction); a Markdown
rendering dependency (a `dependency-update` stop for a subset the standard library renders);
naming the tag (wrong tree).

## Impact

- Documentation: the packet source; `audit/AUDIT_README.md`; `org/RELEASE_PLAN.md` item 10.
