## For agents — Concurrency

Installed by Surfaceplate. Do not edit this file in an adopting repository.

- **One writer per working tree.** Only one agent or process may hold write access at a time.
  Independence of *task* is not independence of *write path* — assess how the write actually
  happens, not whether the work looks separate.
- **Handoff is explicit and complete.** Before starting work on a tree, confirm the previous
  session is closed, its editor buffers are closed, and its work is committed. A clean
  `git status` does not mean nothing is pending — a loaded buffer is a pending write regardless.
- **Concurrent work uses separate checkouts (worktrees), never a shared tree.** But a worktree
  isolates the index, not the hooks, and `core.hooksPath` can be redirected at global or system
  scope with no diff to show for it. Read the resolved hooks path
  (`git config --show-origin --get-all core.hooksPath`) and the common Git directory
  (`git rev-parse --git-common-dir`) — never infer what runs from a clean diff or a file's mere
  presence.
- **A generated, tracked artefact reconciled against its own source is not a merge conflict.** It
  merges cleanly, and the check that reads it then passes against the wrong set. Treat this as a
  live risk in any worktree touching a generated register, manifest, or index.
- **Serialising work in one tree is a legitimate alternative to worktrees**, not a lesser one —
  choose on the real cost of each.
- **Re-read shared state at the moment you brief or instruct from it.** Reading alone is not the
  hazard; briefing or planning from a stale read is.
- **Missing code is a stop condition, not a task.** If a required symbol, file, or interface does
  not exist, stop and report — do not write it.
