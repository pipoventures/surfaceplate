## For agents — Provenance and lineage

Installed by Surfaceplate. Do not edit this file in an adopting repository.

- Classify every value whose origin matters, using this standard's shared taxonomy. An
  AI-proposed value never silently becomes a model-calibrated or sourced fact — that promotion is
  a recorded human decision.
- AI may assist discovery, drafting, and reasoning; it must never own a material numerical path.
- Trace a material result to the application, input version, method and version, configuration,
  code revision, run identifier, timestamp, and output. Record AI provider, model, and prompt
  version for a completed AI-assisted run — never invent placeholder outputs for a failed one.
- Never hide a manual adjustment in UI or calculation code — every deviation from the automated
  path is an override record. High, material, or output-affecting overrides must route through
  approval; `pending`/`rejected` overrides never take effect.
- Label non-live capability at the point of use, not with one global disclaimer. Never call
  something "validated" merely because automated checks passed. Keep lifecycle, validation,
  approval, and run status distinct — always.
