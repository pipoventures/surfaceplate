# Options considered

The log of design alternatives considered before a surface was built, and which one was chosen.

**This file existing is not the practice.** It was created when Surfaceplate was adopted here, so that the `options_before_build` gate has a real place to point at. What the gate asks is that the alternatives for a surface are written down, and one chosen, *before* that surface is built. A file that stays empty while the thing it records happens around it is a finding about this repository, not a satisfied control; the checker cannot tell the difference, because it checks that this file exists and holds no placeholder.

## Log

Each entry records: the surface or feature; the options considered, each in a sentence; the one chosen and why; who decided and when; and the activity it belongs to.

|---|---|---|---|---|

**No options are logged yet.** That is an accurate statement about this repository on the day this file was created, and it stops being accurate the moment a surface with real design choices behind it is built without an entry above.

## Adding an entry

Add the row before the build starts, in the same change that starts it. An entry written after the build records a choice that was not made; that is the gate being satisfied on paper and violated in spirit.
