# R Adapter

Recommended native implementation: `testthat`, `lintr`, `renv.lock`, package-aware tests, deterministic fixtures, and repository-local validation scripts. Keep calculation/domain logic outside Shiny server orchestration. Use explicit schemas and stable structured returns.
